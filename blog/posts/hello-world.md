## 怎么写文章

1. 在 `blog/posts/` 目录新建一个 `.md` 文件，例如 `my-post.md`
2. 打开 `blog/posts/index.json`，按格式登记一篇：

```json
{
  "slug": "my-post",
  "title": "文章标题",
  "date": "2025-01-20",
  "category": "tech",
  "excerpt": "列表页显示的摘要，一两句话",
  "file": "my-post.md"
}
```

3. 推送部署后，博客页就会自动出现这篇文章

## 分类说明

- `tech` → 技术开发笔记（青色）
- `game` → 游戏杂谈（金色）
- `life` → 学习生活记录（紫色）

## 支持的 Markdown

**加粗**、*斜体*、`行内代码`、代码块、表格、图片、引用，都可以正常渲染。
